# Game

## Motion Studio

App local en Python para crear vídeos faceless de motion graphics para YouTube: sube un audio, se transcribe con tiempos por palabra, se generan escenas de motion graphics según el contenido y se renderiza un MP4 con el estilo elegido.

Ver [`motion-studio/README.md`](motion-studio/README.md) para instalación y uso, y [`motion-studio/docs/INVESTIGACION.md`](motion-studio/docs/INVESTIGACION.md) para los repositorios revisados.
